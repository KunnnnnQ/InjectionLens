NOT DONE, ON PURPOSE
--------------------
No complete User-Agent strings were invented. Only the documented TOKEN is stored
and sent. A real client usually embeds the token inside a longer
"Mozilla/5.0 (compatible; <TOKEN>/<version>; +<url>)" string; because that full
string is not published by the vendors, the probe sends the bare token and the
code says so (server/lib/ingest.js).

No crawler or AI-fetcher User-Agent was sent to any third-party host. Every probe
below ran against the local fixture server only.
