About poisoned assistant links

The documented pattern is a page that offers a "summarize with AI" link whose query string is pre-filled with a prompt. One click sends that prompt to the assistant, and the page is then treated as authoritative for later questions.

This page deliberately contains no link to a live assistant host, because the fixture rules forbid one. The pre-filled URL is present only as an inert attribute on a hidden element, so the pattern exists in the page without being reachable.
